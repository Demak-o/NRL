# NRL Touchline Manager

A static, GitHub Pages-ready rugby league manager game. Pick an NRL club, set tactics, and watch the computer run the match automatically with animated players, commentary, score updates, auto interchanges, and a small season ladder.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

## Deploy to GitHub Pages

1. Push this repository to GitHub.
2. Open the repository settings.
3. Enable Pages from the main branch root.

The game uses the bundled 2026 squad seed in `data/squads.js`. The in-game sync button can refresh from the public Wikipedia current NRL squads page when the browser allows it.
